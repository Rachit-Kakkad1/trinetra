## ⚡ The Asymmetric Advantage

Companies use AI to filter, rank, and dehumanize the talent pool.  
**talent-os** gives the individual the same level of intelligence infrastructure.

This is not a job application tool. This is not another AI wrapper.  
**talent-os** is a next-generation career operating system built for the age of agency.

## 🌌 Core Intelligence

talent-os integrates high-signal AI orchestration with a cinematic neural interface to manage your professional trajectory with clinical precision.

- **Neural Profile Layer:** A living, vector-indexed memory graph of your career DNA.
- **Multi-Agent Orchestration:** A decentralized network of specialized agents (JobScout, FitScorer, CVTailor) working in parallel.
- **Neural Dashboard:** A cinematic, low-latency interface designed for deep focus and tactical clarity.
- **Command Palette:** `Cmd+K` interface for instant, fuzzy-search-powered career operations.
- **AI Terminal:** A terminal-native interface for engineers who prefer the speed of the CLI.
- **Multi-Provider Routing:** Intelligent LLM orchestration across OpenAI, Anthropic, and local models.

## 🛠️ The Stack

Built with the same rigor as the systems it interfaces with.

- **Frontend:** React + TypeScript + Framer Motion (Cinematic Animations)
- **Styling:** Vanilla CSS + Tailwind (Custom design system)
- **Intelligence:** Multi-Provider LLM Orchestration
- **Memory:** Vector DB + Local Neural Cache
- **Infrastructure:** Node.js + Express + Future CLI

## 🚀 Quick Start

```bash
# Clone the intelligence
git clone https://github.com/your-org/talent-os.git

# Enter the system
cd talent-os

# Initialize dependencies
npm install

# Configure your neural keys
cp .env.example .env

# Launch the OS
npm run dev
```

> See the [Setup Guide](docs/SETUP.md) for detailed configuration.
