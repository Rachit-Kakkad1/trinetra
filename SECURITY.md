# Security Policy

## 🛡️ Our Commitment

At talent-os, security and privacy are not features—they are the foundation. We are building a system that handles your most sensitive professional data. We take this responsibility with the utmost seriousness.

## 📁 Supported Versions

We currently only support the latest version of talent-os.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## 🕵️ Reporting a Vulnerability

If you discover a security vulnerability within talent-os, please do **not** open a public issue. Instead, please follow these steps:

1. Email your findings to `security@talent-os.dev`.
2. Provide a detailed description of the vulnerability.
3. Include steps to reproduce the issue.
4. (Optional) Provide a suggested fix or mitigation.

We aim to acknowledge all reports within 48 hours and provide a fix within 7 days.

## 🔒 Data Sovereignty

- **Local-First:** Whenever possible, your data stays on your machine.
- **Encryption:** All API keys and sensitive tokens are stored using system-level keychain encryption.
- **Zero-Logging:** We do not log your profile data or LLM prompts on our servers.
- **Open Source:** Our security protocols are open for audit by the community.

## ⚠️ Responsible Disclosure

We ask that you follow responsible disclosure principles:
- Give us reasonable time to fix the issue before making it public.
- Do not exploit the vulnerability for any purpose.
- Do not access or modify data that does not belong to you.
