# Terminal Guide: The Command Line Operating System

For those who prefer the speed of the cursor and the power of the script. The talent-os Terminal is a high-fidelity CLI for managing your career at the speed of thought.

## 🚀 Startup Sequence

```bash
# Initialize the terminal layer
talent-os init

# Authenticate with the neural network
talent-os auth --provider openai

# Synchronize your local memory
talent-os sync --profile default
```

## ⌨️ Essential Commands

### Market Surveillance
`talent scout --market tech --role "Staff Engineer"`  
Triggers `JobScout` to perform a deep-scan of the current market.

### Alignment Analysis
`talent fit --job <job-id> --detail`  
Invokes `FitScorer` to analyze a specific opportunity against your neural profile.

### Document Evolution
`talent tailor --job <job-id> --output ./cv-v2.pdf`  
Directs `CVTailor` to generate a targeted application document.

### Pipeline Management
`talent list --status pending`  
Displays your current opportunity pipeline in a high-density terminal table.

## 📡 Orchestration Commands

`talent run --flow "scout-to-apply" --threshold 90`  
Initiates an autonomous workflow: Scan -> Score -> Tailor -> Notify.

## 🛠️ Configuration

The terminal can be configured via `~/.talent-os/config.yaml`.

```yaml
theme: oceanic-dark
agents:
  fit_threshold: 85
  auto_tailor: true
providers:
  primary: anthropic
  secondary: openai
```
